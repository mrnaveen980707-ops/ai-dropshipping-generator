# Contributing

Thanks for considering a contribution.

## Good first contributions
- improve copy or accessibility
- add validation checks
- add new research prompts
- improve India/global market heuristics
- add export formats
- add tests or documentation

## Workflow
1. Open an issue describing the change.
2. Fork the repository and create a focused branch.
3. Keep changes small and explain the reasoning.
4. Do not add fabricated market statistics or unverifiable claims.
5. Open a pull request with screenshots for UI changes.

## Principles
- Prefer transparent logic over hidden assumptions.
- Separate hypotheses from verified evidence.
- Keep the core tool usable without paid services.
- Do not commit API keys, credentials or personal data.
