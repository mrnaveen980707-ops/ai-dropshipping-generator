# Code of Conduct

We want this project to be useful, practical and welcoming.

Contributors should:
- discuss ideas respectfully
- critique code and claims, not people
- avoid fabricated metrics, fake reviews or misleading evidence
- protect personal data and credentials
- clearly separate hypotheses from verified facts

Harassment, discrimination, threats, doxxing or spam are not acceptable.

Project maintainers may edit, hide or remove contributions that violate these expectations.
